FAST START ON THE SECOND MAC
  git clone https://github.com/Iamyashsiwach/jaagte-raho.git
  cd jaagte-raho
  brew install xcodegen cocoapods
  ./scripts/bootstrap.sh
  ./scripts/run-simulator.sh

Alternatively open iOS/JaagteRaho.xcworkspace in Xcode, select the JaagteRaho
scheme and an iPhone simulator, then Run. Open the WORKSPACE, not the root
Swift package and not just the .xcodeproj. No Apple signing account or provider
credentials are needed for the simulator's offline synthetic demo.
Set SIMULATOR_ID if multiple simulators are available and a specific one is desired.

DEMO FLOW
The dashboard has Hindi, Punjabi, and English, Test Voice, live monitoring,
and a synthetic demo. Start the synthetic demo, hold the closed-eye control,
and observe the bundled voice check-in around 1.5 seconds and a latched alarm
around 3 seconds. The demo is explicitly labeled and never sends a fleet alert.
Use the parked/end-session confirmation to dismiss the latched alarm.
Real camera monitoring requires a physical iPhone, permissions, and parked
calibration (approximately 3 seconds open eyes, then 2 seconds closed eyes).
The simulator demonstrates app behavior, not real fatigue detection accuracy.
See docs/DEMO.md for the live demonstration and acceptance checks.

SAFETY/PRODUCT LIMITS
Prototype heuristics, not validated fatigue diagnosis. Foreground monitoring
only. Camera loss/dim light/background show tracking unavailable. No fictional
dhaba distances or coffee-as-cure claims. Alerts direct the driver to stop safely
and rest. A reply does not mean the driver is safe to continue.
